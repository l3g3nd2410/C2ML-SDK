# Changelog

Version history of `C2ML.API` and the SDK package itself. Each entry matches a tagged
[Release](https://github.com/l3g3nd2410/C2ML-SDK/releases) with a downloadable `C2ML-SDK.zip`.

For the loader's own version history, see the
[loader's changelog](https://github.com/l3g3nd2410/CarX2ModLoader/blob/main/CHANGELOG.md).

## v1.0.0 - Initial public release

- `C2ML.API` - attributes, `BaseMod`, menu widgets, keybinds, config, logging
- HarmonyX bundled for game-code patching
- Full bilingual (EN/FR) guide set
- `C2ML.ExampleMod` reference mod covering the whole API
